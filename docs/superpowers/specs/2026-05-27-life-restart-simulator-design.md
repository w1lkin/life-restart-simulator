# 人生重开模拟器 设计规格书

## 概述

一款暗黑奇幻风的"人生重开模拟器"微信小游戏，纯 HTML 单文件实现，localStorage 本地存储。玩家开局选择种族/身份/愿景，抽卡获取天赋并自由加点，在四种难度下经历由事件驱动的完整人生，最终根据属性和选择获得结局评分与称号。

---

## 一、游戏流程

整体采用**状态机 + 数据驱动混合架构**：开局流程（线性状态机）+ 人生模拟（数据驱动事件引擎）。

```
标题画面 → 难度选择 → 节奏选择 → [开局阶段] → [人生模拟循环] → 结局画面
```

### 1.1 开局阶段（线性）

1. 选择种族（5选1）
2. 选择身份（每个种族约3个）
3. 选择愿景（约10个）
4. 抽天赋卡（从30张池中随机抽取）
5. 属性加点（分配剩余点数）

### 1.2 人生模拟（循环）

每阶段执行：抽事件(2-3个) → 玩家选择 → 属性结算 → 下一阶段

- **精简型**：幼年→少年→青年→中年→老年（5阶段）
- **标准型**：婴儿→童年→少年→青年→壮年→中年→中老年→老年（8阶段）
- 玩家开局时自选节奏

### 1.3 结局触发

- 意外死亡：特定事件致死选项，体质不足时概率提升
- 寿终正寝：完整走完所有阶段
- 命运达成：满足愿景条件后提前触发专属结局
- 特殊终结：道德极端(±100)、财富归零等

## 二、数据模型

### 2.1 种族（5个）

| 种族 | 属性加成 | 特色 |
|------|---------|------|
| 人类 | 全属性 +2 | 均衡，适应性强 |
| 精灵 | 智慧 +5, 魅力 +3, 体质 -2 | 长寿，魔法亲和 |
| 矮人 | 力量 +5, 体质 +3, 魅力 -2 | 锻造大师，坚韧 |
| 龙裔 | 力量 +4, 体质 +3, 魅力 +3, 智慧 -3 | 龙族血脉，稀有强力 |
| 暗精灵 | 敏捷 +5, 智慧 +3, 魅力 -2 | 暗影亲和，高暴击 |

### 2.2 身份（约15个，每种族约3个）

身份决定开局属性基值和初始财富/声望。覆盖贵族、工匠、平民、流浪者、学徒等阶层。部分身份有隐藏后续事件链。

### 2.3 愿景（约10个）

人生目标，决定专属事件池和结局条件。示例：
- 传说勇者（击败魔王）
- 富可敌国（财富 100000+）
- 大贤者（智慧 150+）
- 暗影之主（道德 -80 以下）

完成愿景有额外评分加成和专属结局。

### 2.4 天赋卡（约30张）

- 正面约20张：天生神力、过目不忘、天选之人、龙族血统、商业奇才等
- 负面约10张：体弱多病、社交恐惧、厄运缠身、挥霍无度、诅咒印记等
- 每张卡定义属性修正值，保底机制确保至少1张正面卡

## 三、属性系统

### 3.1 基础六维（范围 1~200）

力量 · 智慧 · 魅力 · 敏捷 · 体质 · 运气

### 3.2 社会三维

| 属性 | 范围 | 影响 |
|------|------|------|
| 财富 | 0 ~ 999999 | 购买装备、投资 |
| 声望 | 0 ~ 1000 | NPC态度、任务等级 |
| 道德 | -100 ~ +100 | 善恶路线分叉 |

### 3.3 门槛机制

事件选项可设置属性门槛（如"力量 ≥ 80"），达标方可选择。复合门槛可解锁隐藏选项（如"力量 ≥ 120 且智慧 ≥ 80"触发隐藏 BOSS 战）。

---

## 四、难度系统

| 难度 | 初始属性倍率 | 抽卡规则 | 事件偏向 | 重roll |
|------|------------|---------|---------|--------|
| 大逆风 | ×0.5 | 抽5选1，负面概率高 | 负面 +40% | 0 |
| 普通 | ×1.0 | 抽5选2，正负平衡 | 正常 | 1 |
| 顺风 | ×1.2 | 抽6选3，正面概率高 | 正面 +30% | 2 |
| 龙傲天 | ×1.5 | 抽7选3，无负面卡 | 奇遇 +50% | 3 |

### 4.1 加点系统

选完天赋后获得可分配点数（龙傲天30点，普通15点，大逆风5点），每点+2属性值，可投入任意六维属性。天赋加成在点数之后叠加。

## 五、事件引擎

### 5.1 事件数据结构

```
event: {
  id, stage[],         // 所属阶段
  minAttr: {},         // 最低属性门槛
  vision: "",          // 愿景专属（可选）
  difficulty: "",      // 难度限制
  weight: 10,          // 抽取权重
  options: [{
    text,              // 选项文本
    require: {},       // 属性门槛（可选）
    effects: {},       // 属性变化
    narrative: ""      // 叙事文本
  }]
}
```

### 5.2 筛选与抽取

1. 匹配当前阶段标签
2. 按难度过滤事件池偏向
3. 过滤属性门槛不达标的事件
4. 优先匹配愿景专属事件
5. 按权重随机抽取 2-3 个

### 5.3 选项呈现

每个选项显示：选项文本 + 属性变化预览。有门槛的选项用锁图标标识，不达标时灰色不可选。

---

## 六、结局系统

结局画面构成：
1. **称号**：如"屠龙勇者""富可敌国""默默无闻"
2. **六维评分**：SS / S / A / B / C / D 六级，基于最终属性值映射
3. **社会属性**：财富、声望、道德终值
4. **叙事总结**：一段基于人生经历的总结文字
5. **综合评分**：S~D 级，综合考虑属性、愿景完成度、财富
6. **愿景完成状态**：✅/❌

---

## 七、本地存储

使用 `localStorage`，两个 key：

### `life_history` — 通关节局列表
```json
[{
  "id": "2026-05-27-001",
  "race": "人类", "identity": "贵族后裔", "vision": "传说勇者",
  "difficulty": "普通", "talents": [...],
  "finalAttrs": {...}, "title": "屠龙勇者", "score": "S",
  "narrative": "...", "timestamp": 1716819200
}]
```

### `life_progress` — 当前进度（仅一份，null 表示无进行中游戏）
```json
{
  "race", "identity", "vision", "difficulty",
  "talents": [...], "attrs": {...},
  "currentStage": "青年", "stageIndex": 3,
  "completedEvents": [...]
}
```

提供"继续游戏"和"生平回顾"（查看历史结局列表）功能。

## 八、视觉风格

### 规范

| 要素 | 规范 |
|------|------|
| 主色调 | 深黑 `#0d0d0d`，深蓝黑 `#1a1a2e` |
| 强调色 | 古铜金 `#c9a84c`，血红 `#c41e3a` |
| 正面/负面 | 墨绿 `#4caf50` / 暗红 `#f44336` |
| 字体 | 标题用衬线体，正文用系统默认无衬线 |
| 边框 | 细线 `#2a2a2a`，选中态金色 |
| 卡片 | 深色背景 + 细微边框，圆角 6-8px |
| 布局 | 单页面条件渲染，手机竖屏优先（375-414px），适配微信 WebView |

### 屏幕列表

1. 标题画面（新游戏/继续/生平回顾）
2. 难度选择
3. 节奏选择
4. 种族选择
5. 身份选择
6. 愿景选择
7. 天赋抽卡（卡牌展示+重roll按钮）
8. 属性加点（六维滑块/加减）
9. 人生阶段事件（叙事文本+选项列表+当前属性栏）
10. 结局画面（完整成绩单）
11. 生平回顾（历史结局列表）

---

## 九、技术约束

- 纯 HTML 单文件（含内联 CSS + JS）
- 无外部依赖，无框架
- localStorage 存取，无服务端
- 移动端优先，微信内置浏览器兼容
- 所有游戏内容数据内联在 JS 中

---

## 十、不在范围内

- 音效/背景音乐
- 多周目继承/转生系统
- 多语言
- 分享/排行榜
- 服务端存储

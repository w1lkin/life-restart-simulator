🎲 事件匹配逻辑

每阶段从事件池中筛选可触发事件，每个事件带有这些标签：

event: {
  id: "young_warrior_01",
  stage: ["幼年","少年"],        // 所属阶段
  minAttr: {力量: 30},           // 最低属性门槛
  vision: ["传说勇者"],          // 愿景专属（可选）
  difficulty: "any",             // 难度限制
  weight: 10,                   // 抽取权重
  options: [...]                // 2-4个选项
}

筛选逻辑：匹配阶段 → 过滤难度 → 过滤属性门槛 → 按权重随机抽取2-3个 → 展示给玩家

📝 事件选项结构

option: {
  text: "拜师学武",
  require: {力量: 50},         // 可选，属性门槛
  effects: {
    力量: +10, 声望: +20, 财富: -50
  },
  narrative: "你拜入名师门下..."  // 叙事文本
}

每个选项造成属性变化+一段叙事文本。门槛选项有特殊视觉标识（🔒），达标才可选取。

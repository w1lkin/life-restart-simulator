💾 本地存储结构

使用 localStorage，两个 key：

life_history = [ {
  id: "2026-05-27-001",       // 唯一ID
  race, identity, vision,    // 开局选择
  difficulty,               // 难度
  talents: [...],           // 天赋列表
  finalAttrs: {...},        // 最终属性
  title: "屠龙勇者",        // 结局称号
  score: "S",               // 综合评分
  narrative: "..."           // 结局叙事
  timestamp                // 完成时间
}, ... ]
life_progress = { // 仅存当前进度，null 表示无进行中游戏
  race, identity, vision, difficulty,
  talents: [...],
  attrs: {...},            // 当前属性值
  currentStage: "青年",      // 当前所在阶段
  stageIndex: 3,             // 阶段序号
  completedEvents: [...]    // 已完成事件ID（防止重复）
}

🎨 暗黑奇幻风视觉规范

要素 规范
主色调 深黑 #0d0d0d，深蓝黑 #1a1a2e
强调色 古铜金 #c9a84c，血红 #c41e3a
正/负面 墨绿 #4caf50 / 暗红 #f44336
字体 标题用衬线体（serif），正文用无衬线（系统默认）
边框/分隔 细线 #2a2a2a，选中态用金色 #c9a84c
卡片 深色背景 + 细微边框，圆角 6-8px
响应式 适配手机竖屏（375-414px宽度），微信WebView优先
